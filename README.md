# Linux Scripts

Este repositório contém scripts utilitários de automação e guias rápidos para auxiliar no gerenciamento, instalação e operação de ambientes Linux.

## 🎯 Objetivo dos Scripts

O objetivo deste diretório é centralizar scripts úteis (`.sh`) para automação de tarefas cotidianas em servidores Linux, tais como:
* Instalação automatizada de pacotes e agentes (ex: Vim, Zabbix Agent).
* Gerenciamento de backups (ex: Veeam).
* Configurações de pós-instalação de servidores.
